## Overview

**Katelyn Codes** is a personal technology and educational platform where I document what I'm learning, explore research, share interesting projects, and make complex technical topics more approachable.

The platform combines my interests in data science, machine learning, software development, and technology ethics with accessible technical communication.

I developed the website using **Astro, JavaScript, HTML, and CSS**, with static deployment through GitHub Pages.

The goal is to create a growing library of technical resources and educational content while developing my frontend engineering and content-management skills.

---

## Platform Features

### Educational Content Series

A series-based format for exploring topics including:

| Series | Focus |
|---|---|
| Research Paper | Breaking down interesting technical and scientific research |
| Fun Project | Exploring open-source projects and creative programming |
| Becoming a Tech Girlie | Accessible introductions to technical concepts |
| Data Structures Deep Dive | Algorithms, data structures, and programming fundamentals |
| AI Experiments | Exploring AI tools, models, and their applications |
| Tech Ethics | Responsible AI, accountability, and technology's societal impact |
| AI & Tech News | Exploring developments in technology and research |

The website includes dedicated series pages and reusable video card components for organizing content.

### Resource Library

A dedicated section for collecting useful learning materials, including research papers, programming tools, tutorials, and technical references.

### Personal Content

The site includes an About page and a Letters section for longer-form writing and updates.

### Responsive Web Design

A custom visual identity built around approachable typography, soft colors, and a playful interface.

## Project Architecture

The application uses Astro's file-based routing system and reusable components to organize site content.

```text
katelyncodes/
├── .github/
├── public/
├── src/
│   ├── components/
│   │   ├── IntroSection.astro
│   │   ├── SeriesGrid.astro
│   │   └── VideoCard.astro
│   ├── layouts/
│   │   └── BaseLayout.astro
│   └── pages/
│       ├── index.astro
│       ├── about.astro
│       ├── series/
│       ├── resources/
│       └── letters/
├── astro.config.mjs
├── package.json
├── package-lock.json
├── tsconfig.json
└── README.md
```

### Architecture Decisions

**Component Reusability**

Shared components help maintain consistent page layouts and content presentation.

**Static Site Generation**

Astro provides a lightweight architecture for publishing educational content without requiring a continuously running application server.

**Content Organization**

Separate page directories organize the site's educational series, resources, and written content.

**Custom Visual Identity**

Rather than using a generic documentation template, the website emphasizes personality and accessibility to make technical learning feel more approachable.

## Run Locally

### Requirements

- Node.js 22.23.4 or newer
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/katelynmccullough/katelyncodes.git
cd katelyncodes
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in your terminal.

### Available Commands

| Command | Description |
|---|---|
| `npm run dev` | Start the Astro development server |
| `npm run build` | Generate the production website |
| `npm run preview` | Preview the production build |
| `npm run astro` | Access the Astro CLI |
